# 部署前检查清单

当用户请求部署检查时，按照以下步骤执行：

## 步骤 1: 环境检查

- 检查环境变量配置
- 验证生产环境配置文件
- 确认数据库连接字符串
- 检查 API 密钥和凭证

## 步骤 2: 代码质量检查

- 运行测试套件
- 检查测试覆盖率
- 运行 linter
- 检查 TypeScript 类型错误
- 运行构建命令

## 步骤 3: 安全检查

- 检查敏感信息泄露（API keys、密码）
- 验证依赖版本（CVE 检查）
- 检查 CORS 配置
- 验证身份认证配置

## 步骤 4: 性能检查

- 检查包大小
- 分析构建产物
- 检查资源优化
- 验证懒加载配置

## 步骤 5: 部署配置检查

- 验证 CI/CD 配置
- 检查 Docker 配置（如使用）
- 验证 Kubernetes 配置（如使用）
- 检查反向代理配置
