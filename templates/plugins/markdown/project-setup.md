# 项目初始化工作流

当用户请求初始化项目时，按照以下步骤执行：

## 步骤 1: 分析项目需求

- 识别项目类型（前端、后端、全栈、库等）
- 确定技术栈（框架、语言、工具链）
- 了解项目规模和复杂度

## 步骤 2: 生成项目结构

- 创建必要的目录结构
- 生成配置文件（package.json, tsconfig.json 等）
- 设置开发工具（lint、format、test）

## 步骤 3: 安装依赖

- 选择合适的包管理器（npm/yarn/pnpm）
- 安装核心依赖
- 安装开发依赖

## 步骤 4: 创建基础文件

- 创建 README.md
- 创建 .gitignore
- 创建示例代码文件
- 创建许可证文件（如需要）

## 步骤 5: 初始化 Git

- 初始化 git 仓库
- 创建初始提交
- 设置 .gitattributes（如需要）
