## 发现的 Bug

### Bug 1: File Watcher 异步清理 ⚠️

**问题**: 在测试之间清理临时目录时，文件可能被其他测试使用
**影响**: 测试不稳定
**修复**: 增加清理延迟或使用唯一的临时目录名

### Bug 2: WebSocket 连接超时 ⚠️

**问题**: 默认 10 秒超时对于无服务器连接测试不够
**影响**: 测试超时失败
**修复**: 增加超时到 30 秒或使用 mock

### Bug 3: 端口冲突测试超时 ⚠️

**问题**: EADDRINUSE 错误导致测试挂起
**影响**: 测试超时
**修复**: 添加更好的错误处理
