# 交互式计划模式 - 快速参考

## 🎯 核心功能

```
/plan <任务>
  ↓
FFT 分析
  ↓
┌─ 简单任务 → 直接执行 ✅
└─ 复杂任务 → 交互式导航 🔄
```

## 📍 导航选项

### 阶段 1: 选项选择

```
📊 Multiple Implementation Options
═══════════════════════════════════
  [1] 保守方案 (MVP)
  [2] 激进方案 (完整重构)
  [3] 平衡方案 (渐进式)
═══════════════════════════════════

选择: [1-3] → 进入确认
选择: 🔄 重新生成 → 生成新选项
选择: ❌ 退出 → 取消流程
```

### 阶段 2: 计划确认

```
📋 计划确认
═══════════════════════════════════
方案: 平衡方案 (渐进式)
⏱️  预计时间: 15s
⚠️  风险等级: medium
═══════════════════════════════════

[1] ✅ 确认执行 → 开始执行
[2] ⬅️  返回上一步 → 重新选择
[3] 🔄 继续计划 → 生成新选项
[4] ❌ 退出 → 取消流程
```

## ⚡ 快捷提示

| 动作 | 结果 |
|------|------|
| 简单任务 | 1-2s 直接执行 |
| 复杂任务 | 3-5s 显示选项 |
| 重新生成 | 最多 3 次 |
| 返回上步 | 无限次数 |
| 随时退出 | 任何阶段 |
