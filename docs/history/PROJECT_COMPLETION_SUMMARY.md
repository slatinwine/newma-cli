## 📋 使用指南

### 启用流式响应

```typescript
import { streamAI } from './src/ai-streaming';

for await (const chunk of streamAI(config, messages)) {
  process.stdout.write(chunk); // 实时显示
}
```

### 启用并行执行

```typescript
import { executeActionsParallel } from './src/execution/parallel-executor';

await executeActionsParallel(actions, executeAction, {
  verbose: true,
  showPlan: true,
});
```

### 启用智能缓存

```typescript
import { getGlobalAICache } from './src/cache/ai-cache';

const aiCache = getGlobalAICache();
const cached = await aiCache.get(request);
if (cached) return cached.content;
```

```bash
# 运行所有基准测试
```
