## 🚀 使用指南

### 启用流式响应

```typescript
import { streamAI } from './src/ai-streaming';

// 基础使用
for await (const chunk of streamAI(config, messages)) {
  process.stdout.write(chunk); // 实时显示
}

// 带回调
await streamAI(config, messages, {
  onChunk: (chunk) => console.log('收到:', chunk),
  onComplete: (reason) => console.log('完成:', reason),
  onError: (error) => console.error('错误:', error),
});
```

### 启用并行执行

```typescript
import { executeActionsParallel } from './src/execution/parallel-executor';

await executeActionsParallel(actions, async (action) => {
  await executeAction(action);
}, {
  verbose: true,    // 显示详细日志
  showPlan: true,   // 显示执行计划
});
```

### 启用智能缓存

```typescript
import { getGlobalAICache, createAIRequest } from './src/cache/ai-cache';

const aiCache = getGlobalAICache();

// 自动缓存 AI 调用
const request = createAIRequest(config, messages);

// 尝试从缓存获取
const cached = await aiCache.get(request);
if (cached) {
  return cached.content;
}

// 调用 AI 并缓存结果
const response = await callAI(request);
await aiCache.set(request, response);
```
