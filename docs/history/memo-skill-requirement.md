# Memo Skill Requirement

创建一个 Newma skill，用于管理和查询 7 个记忆系统。

## Skill 名称

Memo Master - 记忆管理专家

## 功能描述

这个 skill 应该是一个专家级的记忆系统助手，能够：

1. **查询记忆数据** - 快速查询所有 7 个记忆系统的数据
2. **分析使用模式** - 分析用户的开发习惯和使用模式
3. **提供建议** - 基于记忆数据提供智能建议
4. **生成报告** - 生成记忆使用报告和统计

## 具体功能

### 1. 记忆查询工具

- 查询执行历史
- 查询错误解决方案
- 查询用户偏好
- 查询会话上下文
- 查询推理过程
- 查询项目上下文
- 生成综合报告

### 2. 数据分析

- 分析命令使用频率
- 分析错误模式
- 分析开发效率
- 分析学习进度

### 3. 智能建议

- 根据错误历史提供预防建议
- 根据偏好提供优化建议
- 根据推理过程提供学习建议

## 技术要求

- 使用 TypeScript
- 集成现有的 7 个记忆系统
- 提供友好的输出格式
- 支持参数化查询

## 使用场景

用户可以说：
- "查看我的记忆使用统计"
- "分析我最近遇到的问题"
- "生成记忆报告"
- "查看我的开发习惯"
- "有哪些常见的错误"
