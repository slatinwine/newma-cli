## 快速参考

### 触发 Adventure Mode 的关键词

在需求中使用这些词汇：

- "比较" - "比较 JWT 和 Session"
- "或" - "PostgreSQL 或 MongoDB"
- "选择" - "选择一个前端框架"
- "vs" - "React vs Vue"
- "选项" - "有什么选项"

### Plan Choice 选项说明

| 选项 | 说明 | 适用场景 |
|------|------|---------|
| **A - 继续** | 立即执行计划 | 计划完美，直接开始 |
| **B - 修改** | 调整需求重新计划 | 计划不满意，想要调整 |
| **C - 详情** | 查看完整计划 | 想了解更多细节 |
| **D - 取消** | 取消执行 | 改变主意，暂时不执行 |

## 常见问题

### Q: Adventure Mode 总是触发吗？

**A**: 不是。只有当 AI 生成包含 `"type": "choice"` 的响应时才触发。要在需求中明确提到多个选项。

### Q: 可以跳过 Plan Choice 吗？

**A**: 当前版本默认显示。未来可能添加 `--fast` 选项跳过。

### Q: 修改需求会丢失原计划吗？

**A**: 是的。"修改需求"会重新生成计划。建议先查看详情，确认满意后再执行。
